# Video skills

Free video skills for Claude Code, picked from
[awesome-claude-video-skills](https://github.com/zhuyansen/awesome-claude-video-skills).
Each one runs on your own machine with free, open-source tools (ffmpeg, Whisper,
Chrome, Python and Node). None of them needs a paid subscription. Each folder
includes its original MIT `LICENSE`.

| Skill | What it does | Source |
|---|---|---|
| `video-editing` | Rough cut of talking-head clips: joins clips, removes silences and filler words, keeps the last take, transcribes | [vincentventalon/claude-code-video-editing-skill](https://github.com/vincentventalon/claude-code-video-editing-skill) |
| `cut-video` | Tightens long recordings: removes silences, "um"s and dead air, but keeps laughs and comic pauses | [louisedesadeleer/cut-video](https://github.com/louisedesadeleer/cut-video) |
| `shorts` | Turns a long video into vertical shorts with animated captions (Remotion) | [AgriciDaniel/claude-shorts](https://github.com/AgriciDaniel/claude-shorts) |
| `beat-sync-edit` | Cuts a song and raw footage into an edit synced to the beat | [ZiadAbdelkarim/beat-synced-edit](https://github.com/ZiadAbdelkarim/beat-synced-edit) |
| `explainroo` | Makes an explainer or promo MP4 with a local AI voice-over; installs the explainroo CLI the first time you use it | [vincentsch/explainroo](https://github.com/vincentsch/explainroo) |
| `motion-design` | Motion-design launch films in HTML and GSAP | [howseen-ai/claude-motion-design](https://github.com/howseen-ai/claude-motion-design) |
| `text-to-lottie` | Turns a text prompt into a Lottie animation | [diffusionstudio/lottie](https://github.com/diffusionstudio/lottie) |
| `explainer-default`, `explainer-engaging`, `explainer-high-energy`, `motion-broll`, `sound-effects`, `object-separation` | Motion-graphics explainers, B-roll, a sound-effects pass, and subject cut-out with SAM 2 running locally | [Barty-Bart/motion-graphics](https://github.com/Barty-Bart/motion-graphics) |

Optional paid add-ons, which you never need:
- `motion-design` can fetch components from 21st.dev (needs an `API_KEY_21ST`)
  and can use ElevenLabs or Cartesia for voice-overs.
- `explainroo` can use an ElevenLabs voice. Its default local voice is free.
- `sound-effects` lists paid music libraries (Epidemic Sound, Artlist)
  alongside free ones.
